# To-Do List Application (Console-based)

## Description
This is a simple console-based To-Do List application in Python. Users can:
- View tasks
- Add new tasks
- Remove tasks
- Tasks are saved in a text file to persist data between sessions.

## Tools
- Python
- VS Code or any terminal

## How to Run
1. Clone or download the project.
2. Open terminal and navigate to the project folder.
3. Run the program:

python todo.py
